## Description

[PROJECT NAME] is an AR app built in Unity to allow users to place and find stickers in the real world. These stickers are collectible NFTs that represent unique locations for individuals.

## Problem Statement

People want to find unique curated experiences and have a desigre to experience new things all the time, but they don't know where to find them.

## Goal

To create a fun and engaging way to discover unique curated experiences.

## Techstack

1. Unity
2. Google AR Core
3. Supabase
4. Ethereum
