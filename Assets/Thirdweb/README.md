# Thirdweb Unity runtime

Pinned upstream release: [thirdweb Unity SDK v6.1.3](https://github.com/thirdweb-dev/unity/releases/tag/v6.1.3), published 2026-01-14. The release package `thirdweb-unity-sdk-v6.1.3.unitypackage` has SHA-256 `615fd8246a9eee6000004c9d306dbe387b0c094a600fca58fe252c88d4dccc90`, matching GitHub's release digest.

This directory contains the unmodified `Runtime/NET` assemblies, `Runtime/Unity/Http` source, their Unity metadata, and `Runtime/link.xml` from that package; text line endings were normalized to LF. The local `Thirdweb.Unity.Http.asmdef` exposes the upstream HTTP transport to `Tagtag.Blockchain`. Examples, wallet UI, browser plugins, and platform plugins are omitted because this app uses Firebase JWT login and EIP-191 message signing without browser authentication. The package's Apache 2.0 license is in `LICENSE`.

The upstream Unity runtime uses `CrossPlatformUnityHttpClient`; on iOS it selects the thirdweb .NET HTTP client. `ThirdwebEmbeddedWallet` passes `AuthProvider.JWT` to `InAppWallet.Create`, explicitly requests `ExecutionMode.EOA`, authenticates each supplied Firebase ID token with `LoginWithJWT`, signs with `PersonalSign(string)`, and clears the SDK session with `Disconnect`. The Thirdweb project must enable custom JWT authentication for the Firebase issuer and audience before rollout.

Thirdweb v6.1.3 has no in-memory session-store option: its internal `LocalStorage` writes a JSON auth token to the supplied `storageDirectoryPath`. Tagtag passes a unique directory under `Application.temporaryCachePath` and, on iOS, pre-creates the file with `NSFileProtectionComplete`. The adapter deletes the auth file immediately after login, removes the directory on disconnect, purges stale cache directories on next startup, and deletes the legacy `Application.persistentDataPath/Thirdweb/InAppWallet/<clientId>.txt` file from earlier builds. The active SDK wallet retains its session in memory for signing. A process termination during authentication can leave only an iOS-protected cache file until the next startup.

The pinned .NET/Unity SDK does not expose a private-key export method. Thirdweb's supported export UI is its React Connect modal, which is not part of this Unity integration. This version has no wallet export, recovery, or transfer UI independent of Firebase login. Account deletion remains available with an explicit access-loss warning; deleting a Firebase account may leave its embedded wallet and NFTs inaccessible. A future native recovery flow could use `InAppWallet.LinkAccount` with a second verified login method.
