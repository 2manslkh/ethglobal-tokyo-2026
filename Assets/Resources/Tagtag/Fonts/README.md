# tagtag UI fonts

These static TrueType faces were copied from `sticker-app/unity/Assets/Resources/Fonts/` on 2026-09-26. They are used by the adapted Unity UI components and are included in this project so the player has no runtime dependency on the source checkout.

- Instrument Sans Regular and SemiBold: `@expo-google-fonts/instrument-sans` 0.4.2, Google Fonts `ofl/instrumentsans`.
- Bricolage Grotesque Bold and ExtraBold: `@expo-google-fonts/bricolage-grotesque` 0.4.1, Google Fonts `ofl/bricolagegrotesque`.

Each family is redistributed under the SIL Open Font License 1.1. The original notices are `Instrument-OFL.txt` and `Bricolage-OFL.txt` in this folder. Native map cluster labels can use `InstrumentSemibold.ttf` here. Device validation is needed for script fallback and system text sizing.
